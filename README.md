# 🏫 เว็บห้อง 1/2 DSKRU (รวมระบบ) — ใช้ Neon ทั้งหมด

รวมเว็บห้อง + ติดตามงาน + กระดานหักคะแนน ในแอปเดียว เก็บข้อมูลใน Neon (Postgres) ทั้งคู่

## เมนู
- หน้าห้องเดิม: หน้าหลัก / กิจกรรม / เกี่ยวกับเรา / ติดต่อเรา / รายชื่อนักเรียน / คลังโมเมนต์
- /tasks  — ระบบติดตามงาน
- /points — กระดานหักคะแนน (UI เดิม felt-green/gold + stamp animation) **เก็บใน Neon**

## ⚙️ ตั้งค่า .env (มีแค่ตัวเดียวที่ต้องเชื่อมฐานข้อมูล)

    DATABASE_URL="postgresql://...neon.tech/neondb?sslmode=require"
    ADMIN_PASSWORD="รหัสหัวหน้าห้อง"   # กดเข้าโหมดหัวหน้าใน /points
    SESSION_SECRET="สุ่มยาวๆ"          # คีย์เซ็น cookie
    STARTING_POINTS="100"

> ไม่ต้องใช้ Google Sheets / Service Account แล้ว — คะแนนอยู่ใน Neon เหมือน tasks

## 🚀 ขั้นตอนรัน

    npm install
    npm run db:push     # สร้างตาราง Task, Subtask, Student, PointLog

นำเข้าคะแนนเก่า 37 คน (ครั้งเดียว): เปิด Neon -> SQL Editor -> วางไฟล์
prisma/import-points.sql -> Run

    npm run dev

- /tasks  : ติดตามงาน
- /points : อันดับคะแนน, เข้าโหมดหัวหน้า (ADMIN_PASSWORD) เพื่อหัก/เพิ่มแต้ม + เพิ่ม/ลบสมาชิก

## 🎨 ธีม
- /tasks ใช้ aura น้ำเงินเข้ม
- /points คงธีม felt-green/gold เดิม (scope ใต้ .pb-root ไม่ชนกับส่วนอื่น)

## หมายเหตุ
- UI ของ /points เป็นของเดิมทั้งหมด เปลี่ยนแค่ "หลังบ้าน" จาก Google Sheets -> Neon
  (API ชุดเดิม /api/members, /api/points, /api/log ... แต่คุยกับ Prisma แทน)


## 🆕 ระบบเช็คชื่อ (/attendance)
- หัวหน้าเลือกวันที่ -> กดสถานะรายคน (มา/สาย/ลา/ขาด) -> บันทึกลง Neon ทันที
- ปุ่ม "ที่เหลือมาทั้งหมด" เช็คเร็ว
- แท็บ "สรุป" ดูว่าใครขาด+สายบ่อยสุด
- ใช้รายชื่อ Student เดิม + ล็อกอินหัวหน้า (ADMIN_PASSWORD) เดิม
- เพิ่มตาราง Attendance -> ต้องรัน `npm run db:push` อีกครั้งหลังอัปเดตไฟล์


## 🆕 ระบบหัวหน้าห้องเพิ่มเติม (ทั้งหมดบน Neon + ใช้ล็อกอินหัวหน้าเดิม)
- 💰 เก็บเงิน (/money) — หัวหน้าสร้างรายการ+กำหนดยอดเอง, กดจ่าย/ค้างรายคน, รวมยอดอัตโนมัติ
- 📢 ประกาศ (/board) — หัวหน้าโพสต์/ปักหมุด, ทุกคนอ่าน
- 🧹 เวร (/duty) — หัวหน้ากำหนดคนเวรแต่ละวัน (จ-ศ), ไฮไลต์วันนี้
- 🗳️ โหวต (/vote) — หัวหน้าสร้างโพล, ทุกคนโหวต 1 ครั้ง/เครื่อง, เห็นผลเป็น %

เพิ่ม 6 ตาราง (FeeItem, Payment, DutyAssignment, Poll, PollOption, Announcement)
-> ต้องรัน `npm run db:push` อีกครั้งหลังอัปเดตไฟล์


## 🔐 ระบบล็อกอินรายคน + สิทธิ์ (ใหม่ล่าสุด)
ตอนนี้ **ต้องล็อกอินก่อนถึงจะเข้าดูเว็บได้** (ทุกคนมีบัญชี) และหัวหน้ากำหนดได้ว่าใครแก้ระบบไหนได้

### ตั้งค่าครั้งแรก
1. `npm install`  (เพิ่ม bcryptjs)
2. `npm run db:push`  (สร้างตาราง User)
3. สร้างหัวหน้าคนแรก:
   ```
   node prisma/create-user.mjs 69110 31102013 "หัวหน้าห้อง" --head
   ```
   (username=69110, password=31102013 — เปลี่ยนเป็นของจริง)
4. `npm run dev` แล้วเปิดเว็บ -> จะเด้งไปหน้า /login -> ล็อกอินด้วยบัญชีหัวหน้า

### จัดการผู้ใช้
- ล็อกอินเป็นหัวหน้า -> เมนู "จัดการผู้ใช้" (/users)
- เพิ่มบัญชีนักเรียน + ติ๊กว่าให้แก้ระบบไหนได้บ้าง (งาน/คะแนน/เช็คชื่อ/เก็บเงิน/เวร/โหวต/ประกาศ)
- "หัวหน้า" = ทำได้ทุกอย่าง

### หลักการ
- ทุกคนที่ล็อกอินแล้ว = ดูได้ทุกหน้า
- แก้ไขได้เฉพาะระบบที่ได้รับสิทธิ์ (หรือเป็นหัวหน้า)
- ความปลอดภัยบังคับที่ฝั่งเซิร์ฟเวอร์ (API) — ปลอมไม่ได้

## 🔔 แจ้งเตือนเข้ากลุ่ม LINE (งานใหม่ + ประกาศใหม่)
ส่งเข้า "กลุ่ม LINE ของห้อง" โดยเชิญบอท (OA) เข้ากลุ่ม — ทุกคนในกลุ่มได้รับ ไม่ต้องแอดเพื่อนทีละคน

### ตั้งค่า (ครั้งเดียว)
1. สร้าง LINE Official Account ฟรี + เปิด Messaging API (manager.line.biz)
2. ใน LINE Developers Console:
   - เอา **Channel access token** + **Channel secret** ใส่ .env:
     ```
     LINE_CHANNEL_ACCESS_TOKEN="..."
     LINE_CHANNEL_SECRET="..."
     ```
   - ตั้ง **Webhook URL** = https://โดเมนของคุณ/api/line/webhook แล้วกด Verify + เปิด Use webhook
   - ปิด "Auto-reply messages" / "Greeting" ถ้าไม่ต้องการ
   - เปิดให้บอท "เข้ากลุ่มได้" (Allow bot to join group chats) ใน OA Manager
3. **เชิญบอทเข้ากลุ่ม LINE ของห้อง** แล้วพิมพ์อะไรก็ได้ในกลุ่ม 1 ครั้ง
   -> บอทจะจับ groupId อัตโนมัติ + ตอบ "✅ เชื่อมต่อกลุ่มนี้แล้ว"
4. เสร็จ! ต่อไปมีงาน/ประกาศใหม่จะเด้งเข้ากลุ่ม

> Webhook ต้องเป็น URL สาธารณะ (ใช้ได้หลัง deploy เช่น Vercel) — ตอนรันในเครื่อง localhost
> LINE เรียกไม่ถึง ถ้าจะทดสอบในเครื่องก่อน deploy ให้กรอก LINE_GROUP_ID เองใน .env

### โควต้า/สวิตช์
- ฟรี 500 ข้อความ/เดือน นับรายคน (กลุ่ม 39 คน = 39/ครั้ง ~12 ครั้ง/เดือน) เท่า broadcast
- แนะนำเตือนเฉพาะประกาศ: ตั้ง `LINE_NOTIFY_TASKS="false"`
- ไม่ใส่ token = ไม่ส่ง LINE (เว็บทำงานปกติ)

### ต้องทำ
รัน `npm run db:push` (เพิ่มตาราง Setting สำหรับเก็บ groupId)
